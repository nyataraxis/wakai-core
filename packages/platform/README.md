# Platform Package

Platform adapters and stubs for ads, IAP, and analytics across web, mobile, and desktop.

## Scripts

```bash
pnpm --filter @wakai-core/platform build
pnpm --filter @wakai-core/platform lint
```

## Entry points

- `src/index.ts`
- `src/web.ts`
- `src/mobile.ts`
- `src/desktop.ts`
- `src/types.ts`
