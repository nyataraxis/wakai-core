# Content Package

Content schema, loaders, and versioning for Wakai Core.

## Scripts

```bash
pnpm --filter @wakai-core/content build
pnpm --filter @wakai-core/content lint
```

## Entry points

- `src/index.ts`
- `src/schema.ts`
- `src/loader.ts`
- `src/defaultContent.ts`
- `src/versioning.ts`

## Dependencies

- `zod`
