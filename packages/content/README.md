# Content Package

Content schema, loaders, and versioning for Kanji Alchemy.

## Scripts

```bash
pnpm --filter @kanji-alchemy/content build
pnpm --filter @kanji-alchemy/content lint
```

## Entry points

- `src/index.ts`
- `src/schema.ts`
- `src/loader.ts`
- `src/defaultContent.ts`
- `src/versioning.ts`

## Dependencies

- `zod`
